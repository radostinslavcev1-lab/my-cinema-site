# 🎬 CINEMAX - Личен Стрийминг Каталог за Филми и Сериали

Модерно, пълнофункционално уеб приложение за личен стрийминг каталог, изградено с **Python 3.10+ / 3.11+**, **Flask**, **SQLAlchemy** и интеграция с **Streamtape API**.

> 💡 **Ключово предимство:** Видео файловете **НЕ се съхраняват на хостинг сървъра**, а директно в облачните сървъри на **Streamtape**. Хостингът пази единствено метаданни и Video ID, осигурявайки нулев разход на дисково пространство и неограничен безплатен стрийминг.

---

## 🚀 Основни функционалности

### 1. Публична част (Каталог):
- 🍿 **Начална страница (`/`):**
  - Netflix/Plex стил решетка от карти с плакати, рейтинги, години и жанрове.
  - Featured банер с акцентно заглавие, описание и бутон „Гледай сега“.
  - Търсачка в реално време (с падащо меню за автодовършване).
  - Филтриране по тип: **Всички**, **Филми**, **Сериали**.
  - Филтриране по **Жанр** и сортиране по **Най-нови**, **Най-висок рейтинг**, **Година** и **А-Я**.
- 📺 **Страница за гледане (`/watch/<id>`):**
  - Голям отзивчив вграден видео плеър (чрез адаптивен `<iframe>` с отношение 16:9).
  - **Динамично превключване на епизоди за сериали:** превключване между епизодите без презареждане на страницата и групиране по сезони.
  - Детайлна информация за заглавието, рейтинг, резюме и бърз бутон за копиране на линк.
  - Секция **„Подобни заглавия“**, базирана на сходни жанрове.

### 2. Административен панел (`/admin`):
- 🔐 **Защитен вход (`/login`):**
  - Сесийна автентикация с потребителско име и парола от системните променливи (`.env`).
- 📊 **Табло за статистика:**
  - Броячи на общо заглавия, филми, сериали, епизоди и статус на връзката със Streamtape API.
- 💾 **Два метода за добавяне на съдържание:**
  - **Метод 1 (Ръчно въвеждане):** Поставяне на съществуващ Streamtape линк (`https://streamtape.com/v/...` или embed линк), като бекендът автоматично извлича чистия Video ID.
  - **Метод 2 (Автоматично 2-стъпково качване през API):** Избор на локален видео файл (`.mp4`, `.mkv`, `.avi`, `.mov`), визуален индикатор за напредък (Progress bar) и бекенд обработка:
    1. `GET https://api.streamtape.com/file/ul?login=...&key=...` за взимане на upload URL.
    2. Мултипарт `POST` качване на файла.
    3. Автоматично извличане на получения `file_id` и записване в базата данни.
- 🛠️ **Пълно управление:** Редактиране на заглавия, управление на сезони и епизоди на сериали, изтриване с модално потвърждение.

## 💻 Локално стартиране (Стъпка по стъпка)

### 1. Инсталиране на зависимостите
Уверете се, че имате инсталиран Python 3.10 или по-нов, след което изпълнете в терминала:

```bash
pip install -r requirements.txt
```

### 2. Конфигуриране на `.env`
Файлът `.env` вече съдържа първоначални настройки. Можете да го отворите и да въведете вашите реални Streamtape API ключове:

```env
SECRET_KEY=cinema-local-development-secret-key-12345
PORT=5000
ADMIN_USERNAME=admin
ADMIN_PASSWORD=admin123

# Вземете вашите ключове от: https://streamtape.com/panel/account
STREAMTAPE_LOGIN=ваш_api_login
STREAMTAPE_KEY=ваш_api_key
```

### 3. Зареждане на примерни филми и сериали (По избор)
За да тествате визуално каталога веднага с популярни заглавия (*Интерстелар*, *Дюн 2*, *Stranger Things*, *Breaking Bad*):

```bash
python seed.py
```

### 4. Стартиране на сървъра
```bash
python app.py
```

Отворете вашия уеб браузър на адрес:
👉 **[http://localhost:5000](http://localhost:5000)**

- **Публичен каталог:** `http://localhost:5000/`
- **Админ вход:** `http://localhost:5000/login`
  - Потребител: `admin`
  - Парола: `admin123`

## ☁️ Безплатен деплой в облака

### Вариант А: Деплой в Render.com (Препоръчително)

1. **Качване на кода в GitHub:**
   - Създайте ново хранилище в GitHub и качете файловете от проекта.
2. **Създаване на безплатна PostgreSQL база (в Render):**
   - В Render натиснете **New +** -> **PostgreSQL**.
   - Изберете безплатния план (Free) и копирайте **Internal Database URL** (или External).
3. **Създаване на Web Service (в Render):**
   - Натиснете **New +** -> **Web Service**.
   - Свържете вашето GitHub хранилище.
   - **Environment:** `Python 3`.
   - **Build Command:** `pip install -r requirements.txt`.
   - **Start Command:** `gunicorn app:app` (Render автоматично засича и `Procfile`).
4. **Задаване на Environment Variables в Render Dashboard:**
   - `DATABASE_URL` = (Поставете линка към PostgreSQL от стъпка 2). *Приложението автоматично коригира `postgres://` към `postgresql://`*.
   - `SECRET_KEY` = генериран таен ключ.
   - `ADMIN_USERNAME` = вашето админ потребителско име.
   - `ADMIN_PASSWORD` = сигурна админ парола.
   - `STREAMTAPE_LOGIN` = вашият Streamtape Login.
   - `STREAMTAPE_KEY` = вашият Streamtape API Key.
5. Натиснете **Deploy** – вашето приложение ще бъде активно с безплатен HTTPS домейн (`https://your-app.onrender.com`)!

### Вариант Б: Деплой в PythonAnywhere

1. Регистрирайте безплатен акаунт в [PythonAnywhere](https://www.pythonanywhere.com/).
2. В раздел **Files** качете файловете на проекта или ги клонирайте през Bash конзолата:
   ```bash
   git clone <линк_към_хранилището>
   cd <папка>
   pip install --user -r requirements.txt
   ```
3. В раздел **Web**:
   - Натиснете **Add a new web app** -> изберете **Manual configuration** -> **Python 3.10** или по-нов.
   - В **WSGI configuration file** отворете файла и напишете:
     ```python
     import sys
     import os

     project_home = '/home/вашето_потребителско_име/my_cinema_project'
     if project_home not in sys.path:
         sys.path = [project_home] + sys.path

     from app import app as application
     ```
   - В раздел **Virtualenv** посочете пътя към вашата инсталация (ако ползвате venv).
   - Натиснете зеления бутон **Reload**.
   - Вашият сайт работи на `https://вашето_потребителско_име.pythonanywhere.com`.

## 🔑 Как се взимат Streamtape API ключовете?

1. Регистрирайте се или влезте в [Streamtape.com](https://streamtape.com).
2. Отидете в панела **Account Settings** / **API**:
   - `API Login` (често низ от букви и цифри).
   - `API Key` (секретен ключ).
3. Поставете ги в `.env` файла или в Environment Variables на вашия хостинг.

- Защита от атаки с константно време (`hmac.compare_digest`) при проверка на паролата.
- Използване на `secure_filename` и проверка на позволените видео разширения при качване.
- Автоматично почистване на временните файлове от диска веднага след трансфера към Streamtape.
- Защита срещу мрежови разпадания със Streamtape с ясни съобщения за грешки.
